Very Lemon Nodes（非常柠檬节点）

A complete node guide designed for everyday users: covering all nodes including image input, models & LoRA, dimensions, sampling, saving, group toggles, matting, routers, text inference, and list tools.

Common Node Operations

  • F1 shortcut: quick entry to the 5 most commonly used nodes.
  • F2 shortcut: align the selected nodes (Pro feature).
  • Single-click a group title: toggle the group on/off.
  • Shift + single-click a group title: Solo-enable that group exclusively (Pro feature).
  • Double-click a node title: open the node properties panel.
  • Linked multi-line text boxes: to reduce the node footprint, two or more adjacent multi-line text boxes are linked with elastic heights.
  • Plug-in nodes connect anywhere: to simplify workflow building, nodes in the Feature Completion（功能补全）group can be plugged into any free input port of any node nearby and take effect immediately.

Fullscreen Viewer (💠)（全屏浏览）

After entering fullscreen, an image is automatically split into two views side by side: the left is the overview view (the whole image scaled to fit the frame, to see the big picture), and the right is the detail view (1:1 original pixels, to see the fine details); the red viewfinder frame on the overview shows the current viewing region of the detail view — drag or resize the frame and the detail view follows in sync, what you see is what you get. (Image loading nodes are free; fullscreen for image generation comparison is a Pro feature)

Highlights

  • Fullscreen dual-image comparison: A/B images side by side, supporting both "slide follow" and "click to switch" comparison methods, and you can also view a single image.
  • Overview ⇄ Detail linkage: see the whole picture on the left, 1:1 original pixels on the right; the red viewfinder frame is the "lens" of the detail view — point where you want to look.
  • Free zoom & pan: the detail view supports scroll-wheel zoom (50% – 300%) and drag-to-pan, with one click back to 1:1 original pixels.
  • Five comparison modes: compare both overview + detail / overview only / detail only / overlay only / none.
  • Overlay switching: A image overlay ⇄ B image overlay, great for before/after effects on masks and overlays.
  • Multi-image paging: with multiple results you can flip left/right, and the A/B image groups page in sync.
  • Free layout: the left/right panels can swap positions, the overview view can be hidden, and the center divider can be dragged to adjust the width.
  • Property write-back: comparison mode and overlay selections made in fullscreen are automatically synced back to the corresponding properties of the save node, staying consistent next time.

Single Image Loader（单图加载器）

Group: Very Nodes（非常节点）, free node.
Loads an image and converts it into usable image data: auto-corrects photo orientation, supports multi-frame animations, compatible with 16-bit grayscale and alpha channels, and can optionally align dimensions to a numeric value.

Highlights

  • Auto photo orientation correction: EXIF orientation info is auto-corrected, so vertical phone photos no longer lie sideways.
  • Multi-frame & grayscale support: animations are read frame by frame; 16-bit / 32-bit grayscale images are auto-normalized to standard 8-bit grayscale.
  • Alpha channel preserved: images with transparency are processed as RGBA, so transparent regions are not lost.
  • Dimension alignment: size_align can align the output dimensions to a specified value, making it easier to stitch with downstream nodes.
  • Image list append: appends the loaded results to the end of the input image_list, accumulating image by image.

Highlights

Single Image Loader (Mask Painting)（单图加载器(遮罩绘制)）

Group: Very Nodes（非常节点）, paid node.
Load an image and hand-paint a mask directly inside the node: brush, erase and fill as you like; the mask is recorded as vector actions (lossless undo, import/export), and can be merged with the original image's alpha channel and expanded before output — suitable for local repainting / Outpainting / matting scenarios.

Highlights

  • What-you-see-is-what-you-get painting: brush, erase and flood fill operate directly on the node canvas; brush size, opacity and edge feathering are adjustable in real time, with a circular cursor previewing the stroke.
  • The mask is vector, not bitmap: strokes are recorded as a vector action stack with 30-step undo / redo that is lossless and reversible; it is also restored after the workflow is saved and reopened.
  • Smart merge with original Alpha: the source image's alpha channel is read automatically and can be unioned with the hand-painted mask (merge_alpha) or completely overridden.
  • Mask expansion: mask_expand expands the mask outward by pixels, convenient for reserving margin for diffusion (Inpaint/Expand).
  • One-click mask preview: mask_overlay fills mask areas with the brush color while keeping the rest of the original image — preview the composite right after painting.
  • The mask travels with you: mask metadata can be exported / imported as JSON, auto-recalculated when the image or size changes; with auto_save on, reopening the workflow with the same image auto-restores the mask.
  • Multi-input priority: supports external image / image_list / mask inputs; source image priority is batch task > image > first image of image_list > node-loaded image.

Lemon Image Size（柠檬图像尺寸）

Group: Very Nodes（非常节点）, free node (size favorites limited to 3 entries; unlimited for Pro users).
Pick "ratio + total megapixels" or "long side / short side", and the node automatically computes the width/height and generates an empty Latent of the corresponding size — connect a loader / sampler and you are ready to generate.

Highlights

  • Ratio + pixel dual lock: change the width and the height is computed automatically (and vice versa), the ratio is never broken; you can also switch to "long side / short side" or free input.
  • Smart alignment: width/height are auto-aligned to size_align (default 16); if one side exceeds max_edge (default 8192) or the total pixels exceed max_megepixels (default 8MP), it auto-shrinks with a notice — limits can be adjusted in system settings.
  • One-click portrait/landscape switch: the composition button swaps width/height between portrait and landscape; a ratio below 1 is auto-detected as portrait, above 1 as landscape.
  • Common size favorites: one-click favorite of the current ratio / pixels / size, sorted by "Size > / Long Side > / Short Side > / Pixels > / Ratio >", applied on selection.
  • Model-aware Latent: once a model is connected, the Latent is generated per the model's downsampling ratio and channel count (width/height and a placeholder Latent are still output without a model).

Lemon Loader（柠檬加载器）

Group: Very Nodes（非常节点）, free node (model favorites limited to 3 entries; unlimited for Pro users).
One node replaces the whole "model + CLIP + VAE + positive prompt + empty Latent" chain: loads the model and text encoder, mounts LoRAs, encodes prompts, generates the Latent, and has built-in model caching (no repeated loading when parameters are unchanged).

Highlights

  • All-in-one loading: model (UNet / checkpoint / GGUF), CLIP, VAE and multiple LoRA groups configured at once, outputting model / positive / vae / latent / clip (the negative prompt no longer leaves the loader — the "Lemon Sampler（柠檬采样器）" now supplies it itself).
  • Smart model caching: fingerprint-based caching for model, prompt and Latent separately; unchanged parameters hit the cache directly without re-loading or re-encoding.
  • Model family organization: ckpt_family manages models by directory family, supporting "favorites" of model combinations with parameter presets, loaded from the dropdown.
  • AuraFlow / differential diffusion: aura_flow enables AuraFlow sampling shift; differential diffusion adaptively adjusts mask strength by denoise progress, for use with inpainting.
  • Edit mode: auto-selects Qwen visual encoding or Krea2Edit semantic encoding with a reference image, suited to image editing / repainting workflows.
  • Built-in local repainting: connecting mask automatically injects a noise mask; combined with the "Reverse/Zero-Out/Inpaint" control node, inpainting is supported.
  • SeedVR2 support: model names containing seedvr2 auto-switch to SeedVR2 preprocessing and tiled VAE encoding (requires ComfyUI ≥ 0.28.0).

Feature Completion Group（功能补全分组）

How Control Nodes Work

Nodes in the "Feature Completion" group are collectively called control nodes: they don't produce images directly but "inject" parameters into target nodes in the same workflow (loaders / samplers / savers), to supplement parameters that are less commonly used on the target node's panel.

  • No wiring needed on outputs: output ports of control nodes generally don't need wiring — the target node is found automatically within the same workflow and the parameters are applied; if you do wire it, the wired control node takes priority.
  • Multiple same-type nodes, pick one: when multiple control nodes of the same type exist in one workflow, only the one with the largest node number takes effect.
  • Muting disables: Muting / Bypassing a control node stops its parameters from being injected into the target node.

TTP Group（TTP 分组）

Group Overview（分组速览）

The TTP tiling pipeline is designed for large images and low-VRAM scenarios: TTP Split（TTP分割） cuts a large image into coordinate-tagged tiles, TTP Merge（TTP合并） stitches them back by coordinates with gradient blending, TTP Decode（TTP解码） tiles directly in latent space and outputs an image list through the VAE. Use with any per-tile processing node.

TTP Split（TTP分割）

Group: Image Tools（图像工具）, free node.
Cuts a large image apart ("tile → process per tile → gradient blend") and stitches it back, solving VRAM exhaustion on large images in upscaling, repainting and similar scenarios.

Highlights

  • Four tile balancing schemes: shrink-to-even / fixed-size even edges / fixed-size edge cut / fixed-size bounce-back, matching different upscale needs.
  • Overlap prevents seams: the overlap region gives neighboring tiles material for gradient blending, so the stitched result has no seams.
  • Coordinate alignment: alignment keeps tile coordinates aligned to model requirements (default 64); scale scales the output coordinates for upscale chains.
