## ✨ 柠檬不是整合包，也不是乐高积木

用过AI生图生视频的朋友都遇到过两种极端：

- **一键运行整合包**：全包了，但运行流程、参数设置全都整合封闭，整合包给什么就只能用什么；
- **祖传节点搭建工作流**：灵活是灵活，但每次出图都要拖一长串，接线接到眼花，每个节点就是一颗“乐高积木”。

非常柠檬节点走的是中间路线：**模块化刚刚好**——把高频操作按"功能"封装成一个节点。要什么，拖什么；想改，换节点就行。

## ✨ 功能亮点

### 1. 工作流简洁：模块化刚刚好

- **不是整合包**：每个节点都是独立模块，链路自由组合，不锁死你的工作流。
- **不是乐高积木**：相关功能封装成一个节点，比如「柠檬加载器」= 模型 + CLIP + VAE + 正向提示词 + 空 Latent；「柠檬采样器」= 采样 + 分步预览 + 矩阵预览 + FLS 增强 + SeedVR2 多轮放大。
- **少装一堆节点包**：以前为了用某个节点包里的一个节点，不得不装下一整个包；柠檬节点把高频功能集中封装，custom_nodes 目录和右键菜单都清爽了。
- **结果**：同样的出图需求，画布上的节点更少，接线更少，想改哪里改哪里。

### 2. 功能补全外挂：界面精简，需要时随手接

- **原创玩法**：原创“外挂式节点、任意节点皆可接入”，参数即可生效设计。但世界之大，不敢说是绝对没有先例，必须谦虚。
- **主节点保持清爽**：难得一用的参数不占节点空间，不用天天对着用不到的参数，界面清爽不被打扰。
- **外挂节点，接入即生效**：需要专业控制时，把功能补全节点拖进画布、接入口就生效；不连线也能注入同一条工作流的对应节点。
- **省心省力**：想用哪个挂哪个，用完撤掉也不影响主链路。

### 3. 图源处理，加载器就包办了

图片的前期准备不需要外部工具，在工作流里就能完成：

- **裁切 / 旋转 / 缩放**：画布上直接拖裁切框，所见即所得。
- **扩图**：遮罩外扩像素，Outpainting 一步到位。
- **遮罩涂抹**：画笔 / 擦除 / 填充随手涂，矢量记录，可导出导入，换图自动换算。
- **多图合并**：副图缩放、拼接成一张图，按需导出任意一张。

**平行节点间无缝切换**：四种图片加载器（单图 / 多图 / 裁切缩放 / 遮罩绘制）在标题栏一键互切——当前选中的图片、已接的连线、参数缓存全部跟着走，切完直接继续干活，不用重建工作流。

### 4. 尺寸预设：不同模型不用换尺寸节点

正常情况下，换一个模型就得换对应的 latent 尺寸节点；柠檬的尺寸预设不用——

- **自动识别，一套逻辑护驾到底**：图生图、文生图都走同一套尺寸预设逻辑，不用为不同模型单独接 latent 尺寸节点。
- **横竖构图切换**：横图 / 竖图一键切换，构图比例随手定。
- **百万像素尺寸推算**：直接按总像素出尺寸，1MP、1.5MP……输入即得。
- **按比例出尺寸**：比例 + 总像素，自动算宽高，生成空 Latent 直接接采样器。
- **按长短边推算尺寸**：指定长边或短边，另一条边自动算。
- **收藏你的专用尺寸**：常用的画幅尺寸收藏起来，下次一键选用，不用再翻参数。

### 5. 模型加载器：三合一，一个节点通吃

- **三件套一体化**：模型 + CLIP + VAE 的配置、注入、编码一次完成，配合采样链路输出即用。
- **AIO 模型**直载：识别 AIO 复合模型，开箱即用。
- **GGUF 加载**：GGUF 量化模型（含 GGUF CLIP）直接加载，低显存也能玩大模型。
- **SeedVR2 放大直选**：加载器里选中 SeedVR2 模型即可放大出图；要更多参数调整，外接 SeedVR2 放大控制节点细调。
- **文生图、图生图一个节点通吃**：不需要切换节点，同一加载器搞定。QwenEdit、Image2.1、Krea2Edit 的加载方式和图像注入结构各有各的规矩，光接线就劝退一半人。非常柠檬把适配全部藏进节点里：**不用搭专用工作流**，控制节点拖进画布、接上图片注入即可生效。想试哪个模型就接哪个，主工作流一行不改。

### 6. 模型配置预设：收藏一次，一键部署

- 按模型家族加载模型列表，告别以前模型装满硬盘，列表装满列表下拉框的尴尬。
- 每个模型的完整配置（模型文件、CLIP、VAE、编辑方式、LoRA、量化等）可以**保存为预设并收藏**。
- 下次用直接**一键调用部署**，不用重新填参数。
- 告别「不同模型 = 不同工作流」的切换方式——一个加载器，收藏夹里切换模型配置。

### 7. LoRA 管理：别再当"丢了钥匙的宝箱"

玩 ComfyUI 的人都有这个痛：LoRA 越收集越多，但**每个 LoRA 的最佳强度、触发词记在哪**？笔记本、截图、还是脑子？记不住的话，收集再多也是丢了钥匙的宝箱。

- **最佳强度、触发词随 LoRA 一起存**：在 LoRA 管理器里把每个 LoRA 的最佳强度（上下限与默认值）和触发词记好，跟着配置走，换工作流、换机器都不丢。
- **一键加载到最佳强度**：加载器里选中即按默认强度挂载，不用每次手调。
- **一键复制触发词**：触发词一键复制，粘贴进提示词就完事。
- **多组叠加**：列表式挂载多组 LoRA，每组独立 启用 / 模型 / 强度，CLIP 可选注入。

### 8. 一体化多阶采样器：告别蜘蛛网

多阶段采样（先粗出、再分段精修）原本要拉一长串采样器互相接力，画布接线像蜘蛛网。

- **一个节点部署多阶采样**：「柠檬采样器(多阶段)」把加载器 + 采样器合并，采样完成把 模型、条件、VAE、Latent、提示词 等中间结果一并输出，想接哪段接哪段。
- **采样预览 sigma 图自动保存**：分步预览的 sigma 图也能自动存档，复盘采样过程有据可依。
- **分阶段步数控制**：配合「步数控制」控制节点指定各阶段开始 / 结束步数区间，不连线即生效。
- **清爽可读**：同一套多阶段逻辑，节点更少、接线更直，改起来一目了然。

### 9. 保存节点：出图后的每一个动作都替你想到

- **AB 对比**：⚔️ 开关一键对比 A / B 两组图，不用来回切换文件。
- **多格式储存**：PNG / JPG / WEBP 任选，PNG 带元数据不算什么——**JPG、WEBP 也能携带完整参数元数据**。
- **元数据可提取**：配套提取节点能把参数读回来，二次利用不丢信息。
- **EXIF 记录**：简要参数设置 + **跑图时间记录**（各节点耗时都在里面），复盘调参有据可依。
- **author 署名**：存图留下你的大名。
- **路径自由**：自定义文件名与存储路径，一键存到桌面。
- **出图后一键动作**：打开、复制、打开所在目录、**闪送到图片加载器**（直接送进画布继续处理）。
- **全屏双图对比看细节**：总览 + 细节双视图联动，滑动抹开 / 点击按住切换，1:1 像素级检查，红色取景框框选任意细节——AB 对比的技巧细节拉满。

### 10. 文本推理：把 ComfyUI 当专业应用软件用

不是"又一个 LLM 节点"，而是把各种业态推理模型都考虑到的推理全家桶：

- **本地 / 远程通吃**：本地 LLM、CLIP 模型、HTTP 外接服务都接得住。
- **细致调参，当常规推理节点用**：高级参数模式提供完整参数调整，需要精细控制时，它就是专业推理节点。
- **傻瓜式专家模式**：随手拉一个专家出来，就能把 ComfyUI 当专业独立应用软件用——翻译、提示词扩写、图像反推、OCR、摘要、关键词提取……12 种专家内置，零配置上手。
- **自定义专家**：你的专属专家模式自己定义，工作流即应用。

### 11. 弹性双文本输入框：双框弹性，一空间多用

推理节点用得最多，但不是推理节点的专属：

- **双文本输入框**：上框、下框两个文本框，系统提示 / 用户输入分工明确。
- **弹性高度模式**：两框自由、上框占满、下框占满、聚焦撑大、失焦还原……7 种高度模式切换，节点面积怎么用你说了算。
- **聚焦自动撑大**：点哪个框，哪个框展开，失焦自动还原，长文本也不挤。
- **专家模式自带结果反馈**：不需要另接文本接收节点，推理结果直接在节点内显示，画布省一段连线。

### 12. 忽略多框：把 rgthree 的"好用又不好用"变好用

rgthree 的忽略多框好用，但总差点意思——一组 group 配一个，拖一长串。柠檬忽略多框把画布管理一次做全：

- **一个面板管所有组**：不用再"一组 group 配一个忽略多框"，一个节点搞定全部编组管理。
- **虚拟编组**：不用真的建 group，按条件虚拟归组，想管哪组管哪组。
- **软硬停用**：软停用、硬停用自由切换——想暂时关掉用软的，想彻底隔离用硬的。
- **排序与别名过滤**：按关键字过滤、排序，组再多也能一眼找到。
- **一键节点召唤**：一键召唤节点，要用的节点立刻归位，不用满画布找。
- **组安全保护**：保护组不被误删误改，折腾的时候大胆一点。
- **反向停用**：反向停用一组，反手就把要排除的组隔离开。
- **全局快捷键 + 分组标题栏操作**：面板行内操作之外，快捷键随手即用。

### 13. 随机种子：把 rgthree 的痛点都解决掉

针对 rgthree 随机种子节点，把几个老问题一次解决：

- **每次都能成功随机**：点击 🎲 立即随机生效，不需要"先运行一次"激活。
- **无节点化部署**：随机机制完全由前端 DOM 按钮驱动（🔒固定 / 🎲换个 / 🧷上个 / ⚓锚点一键操作），不依赖节点连线与后端逻辑，点哪都灵。
- **一键广播**：标题栏点 📡，全工作流 seed 统一跟随，接收端有 🟢🟡 可视化标记。
- **全局默认可配**：随机上限、初始状态（固定/随机）、锚点默认值都有全局设置，一次配置处处生效。
- **四模式循环**：🔒固定 / 🍀随机 / ➕递增 / ➖递减，配合锚点与"上个值"随时回退。

### 🍋 非常节点 —— 图片从进门到出门

- **单图加载器**：最基础的图片入口。自动转正拍照方向、支持多帧动图、兼容 16 位灰度与透明通道。
- **单图加载器(裁切缩放)**：画布上直接拖拽裁切框，所见即所得地裁切、旋转、缩放，支持批量列表与蒙版同步。
- **单图加载器(遮罩绘制)**：画一笔就有的遮罩。画笔、擦除、填充随手涂，矢量记录，无损撤销，可导出导入，换图自动换算。
- **多图加载器**：画廊式加载多张图。主图模式最多 5 张（1 主图 + 4 副图），无主图模式最多 6 张；副图可缩放、合并成拼接图，按需导出任意一张。
- **柠檬图像尺寸**：一套尺寸预设逻辑通吃文生图/图生图与所有模型。比例 + 总像素、长边 / 短边、百万像素推算、横竖构图切换，常用尺寸可收藏，自动生成空 Latent 直接接采样器出图。
- **柠檬加载器**：一个节点顶一条链路。模型 + CLIP + VAE + 正向提示词 + 空 Latent，支持 AIO / GGUF 直载，参数不变不重复加载。
- **柠檬采样器**：采样增强全家桶。分步预览（sigma 图自动保存）、矩阵预览、FLS 采样增强、SeedVR2 多轮放大，一个节点全搞定。
- **柠檬采样器(多阶段)**：一体化多阶采样，加载器 + 采样器合并，采样后把模型、条件、VAE、Latent、提示词等中间结果一并输出，告别多阶采样蜘蛛网。
- **柠檬图像保存**：AB 对比、多格式元数据（PNG/JPG/WEBP）、EXIF 参数与跑图时间、author 署名、自定义路径、一键打开/复制/打开目录/闪送、全屏双图对比。

## 🛠 安装

**本仓库仅包含说明文档**，节点代码以压缩包形式在 [Releases](https://github.com/lemonoder/ComfyUI-LemonNodes/releases) 发行版中发布：

2. 将压缩包解压到 ComfyUI/custom_nodes/ 目录（解压后的文件夹名保持 ComfyUI-LemonNodes）；

3. 安装依赖：进入 ComfyUI 根目录后运行

   ```bash
   cd ComfyUI
   python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-LemonNodes\requirements.txt
   ```

   （非便携版环境，直接在节点目录内用你的 Python 执行）

   ```bash
   cd ComfyUI/custom_nodes/ComfyUI-LemonNodes
   pip install -r requirements.txt
   ```

   **下载慢？两种镜像加速方法**（二选一即可）

   - **方法一：临时加速**——只在本次安装生效，不改动环境配置，最稳妥：

     ```bash
     python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-LemonNodes\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
     ```

     非便携版环境同理：

     ```bash
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
     ```
   - **方法二：永久加速**——写入全局配置，之后所有 pip 安装都自动走镜像，不必每次带参数：

     ```bash
     python_embeded\python.exe -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
     python_embeded\python.exe -m pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn
     ```

     配置完成后，回到上面执行原始安装命令即可。想改回官方源：

     ```bash
     python_embeded\python.exe -m pip config set global.index-url https://pypi.org/simple
     ```

   **常用镜像源**（把上面命令中的地址替换成下面任意一个即可）

   | 镜像源 | 地址 |
   | :--- | :--- |

   | 华为云 | `https://repo.huaweicloud.com/repository/pypi/simple` |

   > 用临时方式时，`--trusted-host` 后面跟的是同一个镜像域名（如 `--trusted-host mirrors.aliyun.com`）。

   **所需模块**：`pywin32`（Windows 硬件识别）、`cryptography`（注册码识别）、`piexif`（JPG/WEBP 元数据读写）、`opencv-python`（图像处理）、`diffusers`（调度器安装）；
